To make custom cursor image:
	1. Create image(s) of the mouse that you want
	2. Download your design and drag it into the res:// filesystem
	3. Create a 2D Sprite in the scene and attach a script
	4. Create the number of variables that you want for the amount of mouse cursor images you have
		Example: "var arrow = load()"
	5. Drag the file into the parenthesis next to "load" (should look like the example below)
		Example: load("res://assets/cursor/RedWire_Cursor.png")
	6. In the func _ready(), input the following code:
		"Input.set_custom_mouse_cursor(arrow)"
	7. If you have multiple variables/mouse images, you can set it to show the mouse when it has a specific image:
		"Input.set_custom_mouse_cursor(hand, Input.CURSOR_POINTING_HAND)"
